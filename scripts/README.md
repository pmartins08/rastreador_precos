# Scripts operacionais

Esta pasta contém ferramentas de diagnóstico e auditoria que não fazem parte do caminho principal de execução do LapIntel PT.

- `audit_history.py` / `history_audit.py` — auditorias complementares ao histórico e ranking;
- `tier_threshold_audit.py` — verificação de thresholds/tier policy;
- `store_access_probe.py` — diagnóstico controlado das rotas públicas por loja;
- `manufacturer_source_probe.py` — investigação de fontes oficiais de fabricante;
- `rp_promotion_budget_probe.py` — diagnóstico específico de cobertura/economia de campanhas Radio Popular;
- `validate_decision_run.py` — invariantes V9 de histórico, contagens e decisões efetivas.

Scripts one-shot concluídos e respetivo estado de replay foram removidos do repositório após a conclusão do ciclo de desenvolvimento.
