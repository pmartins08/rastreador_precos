# V8.8.6 — validação pós-integração

A primeira run real em `main` deve confirmar os seguintes pontos antes de considerar a release estabilizada:

1. CI, tracker, heartbeat ntfy e persistência terminam com sucesso.
2. Nenhum produto com `GPU_DESCONHECIDA`, `DEDICADA_NAO_MAPEADA` ou `INTEGRADA_SEM_CLASSE_PREMIUM` aparece como Ouro/Diamante.
3. GPUs dedicadas mapeadas mantêm acesso normal a Ouro/Diamante quando o Value o justifica.
4. Comparar distribuição D/O/P/B com a última run V8.8.5 (0/9/112/37) e identificar quais antigos Ouros foram reclassificados.
5. Verificar se a Worten transforma as URLs do sitemap em candidatos após aceitar `/produtos/`.
6. Medir `new_candidates/request` das campanhas e confirmar que uma campanha fraca deixa de dominar segmentos produtivos depois da fase de exploração.
7. Guardar métricas e exemplos reais para a futura apresentação V9/V10.

Se algum ponto falhar, corrigir em branch antes de avançar a próxima funcionalidade.
